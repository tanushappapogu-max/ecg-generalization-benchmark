# AI4BioSig 2026 Overleaf project

This directory contains only the anonymized IEEE-format paper intended for the
AI4BioSig workshop at IEEE BIBM 2026.

## Upload instructions

1. Create a new blank Overleaf project.
2. Upload `main.tex` and the complete `figures` directory.
3. Keep `main.tex` as the project's main document.
4. Compile with pdfLaTeX.

Do not copy `neurips_2026.sty`, the older WMHS `main.tex`, or the older
submission README into this project. The author field is intentionally empty
for double-blind review.

The current manuscript is a seven-page full paper. It carries forward the
existing study and incorporates the reviewer-requested writing revisions and
the post-hoc analyses supported by the saved experimental outputs; it does not
claim that the outstanding near-duplicate audit or second foundation-model
experiment has been completed.
